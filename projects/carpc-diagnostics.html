Automotive CarPC Diagnostics

A hardware repurposing project focused on turning a compact PC into a practical vehicle dashboard platform. It explores live diagnostics, Android Auto integration, and in-car usability.

Objective

  • Support OBD2-based diagnostics

Key Features

  • Compact dashboard build
  • Responsive hardware adaptation

Takeaway

  • Creative hardware reuse
  • Improved dashboard experience
  • Strong practical computing application
